# Superstore-Report

## 📝 Overview

This project focuses on analyzing **Superstore sales data** to uncover key insights into business performance, profit trends, and customer purchasing behavior. Using **Power BI**, I developed an interactive dashboard that visualizes sales metrics, regional performance, and product-wise profitability. The analysis provides data-driven insights to support strategic decisions and improve business growth.

## ✨ Key Features

* 💰 **Sales & Profit Overview** – Track total sales, profit margins, and overall performance.
* 📦 **Category Analysis** – Evaluate product categories and sub-categories contributing to revenue.
* 🌍 **Regional Insights** – Compare sales and profits across different regions and states.
* 👥 **Customer Analysis** – Identify top customers and purchasing trends.
* 📊 **Interactive Dashboard** – Use filters, slicers, and drill-down features to explore insights dynamically.

## ✅ Dataset Information

* **DataSet1- Sample - Superstore.xlsx** used as the main dataset.
* Contains order details such as sales, profit, quantity, discount, customer, and region.
* Data was cleaned and structured to remove duplicates and null values for accurate analysis.
* Enables insights into sales performance, profitability, and regional distribution.

## 🛠️ Tools Used

* **Power BI** – Built interactive dashboards for visual analysis.
* **Excel** – Used for initial dataset cleaning, preparation, and validation.

## 🚀 How to Use

1. Open `sample store.pbix` in **Power BI Desktop**.
2. Interact with filters and slicers to analyze sales, profit, and category performance.
3. Explore insights by region, product type, and customer segment.

## 🗂️ File Structure

* `DataSet1- Sample - Superstore.xlsx`: Dataset containing Superstore order and sales data.
* `sample store.pbix`: Power BI dashboard file with visual analysis.
* `README.md`: Project documentation.
